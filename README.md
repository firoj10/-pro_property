# 🏢 State Link

**State Link** is a modern and responsive **Building Management System** built with React and Material UI. It enables seamless property listings, tenant management, analytics, and an intuitive admin dashboard — all in one place.

---

## 🚀 Features

- Property and unit listings
- Add/Edit/Delete properties
- Tenant management
- Booking and availability system
- Dashboard with charts and stats
- Dynamic Data Tables
- Form validation with file upload
- Beautiful animations and responsive design

---

## 🧩 Technologies & Dependencies

This project uses the following core packages:

| Package | Purpose |
|--------|---------|
| `react` & `react-dom` | Core React libraries |
| `@mui/material` | Material UI components for responsive design |
| `@mui/x-data-grid` | Advanced data tables |
| `@emotion/react` & `@emotion/styled` | Styling support for MUI |
| `@reduxjs/toolkit` & `react-redux` | State management |
| `axios` | For API communication |
| `react-router-dom` | Routing between pages |
| `react-hook-form` | Easy form handling |
| `@hookform/resolvers` & `yup` | Schema-based form validation |
| `react-datepicker` | Date selection input |
| `react-dropzone` | File upload with drag & drop |
| `chart.js` & `react-chartjs-2` | Data visualization and analytics |
| `framer-motion` | Smooth animations and transitions |
| `react-icons` | Popular icon packs |
